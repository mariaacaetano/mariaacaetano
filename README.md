## 💻 Projetos em destaque

### [Leonor](https://github.com/mariaacaetano/Leonor)

Plataforma de organização financeira pessoal e empresarial, com controle de entradas, despesas, cartões e visão geral do orçamento.

**Tecnologias:** Python, FastAPI, React, TypeScript e PostgreSQL.

### [Swine DataMed](https://github.com/mariaacaetano/swine_datamed)

Aplicação para explorar relações entre sintomas e doenças em suínos, com preparação de dados clínicos e comparação de mecanismos de inferência.

**Tecnologias:** Python, Django, React e aprendizado de máquina.

### [Aplicativo de Logs Transparentes — Fábrica de Software](https://github.com/fabricadesoftware-ifc)

Projeto colaborativo relacionado a logs de transparência, desenvolvido no contexto da Fábrica de Software do IFC Araquari.
